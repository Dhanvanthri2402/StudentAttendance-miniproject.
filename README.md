University Class and Attendance Management API

This project is a REST API built with Spring Boot and Hibernate for managing university classes and attendance. I designed it to handle the complex relationships between students, professors, courses, and class sessions using a highly relational MySQL database.

A major focus of this project was implementing strong architectural patterns. I used Data Transfer Objects to shield the database entities from the presentation layer, which successfully prevented the infinite recursion issues that often happen with Hibernate. I also set up global exception handling to catch server errors and validation failures, ensuring the API always returns clean, informative responses instead of raw stack traces. The core business logic is strict by design. For example, the system prevents students from marking their attendance unless a professor has actively marked that specific class session as live. I also included custom Spring Data JPA queries to automatically calculate attendance analytics for professors based on their session history.

The application is powered by Java and Spring Boot, utilizing Spring Web, Data JPA, and Validation dependencies. The data is stored in a MySQL database mapped through Hibernate. To run this project locally, you will need to clone the repository and update the application properties file with your local MySQL database credentials. Once the database connection is configured, you can run the application directly through your IDE or by using Maven.

The API is organized into several main controllers to ensure a clean separation of concerns. The professor endpoints allow you to register new professors and retrieve their details securely. The course endpoints handle creating courses, assigning them to professors, and enrolling students. The class session controller manages the scheduling of classes and includes the logic for starting or ending a live session. Finally, the student endpoints handle student registration and the core attendance marking system, which strictly validates check-ins against the real-time status of the class session.
